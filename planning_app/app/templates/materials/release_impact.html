This is a what-if view. Every open PO release is treated as withheld until selected. Releases marked as committed are included in the baseline supply. Committed and staged decisions are saved and survive the daily sync — a committed release drops off automatically once it is fully received into stock. Outstanding PO value is used as the cash proxy; it is not an accounts-payable balance. {% if scope == 'all' %} Jobs are only counted as unlocked when all imported fabric and component requirements are covered. {% else %} Fabric-only mode: component shortages are ignored when deciding whether a job is unlocked. {% endif %}
1. Start with the baseline

The baseline includes available stock and any PO releases you have marked as committed. All other open PO releases are treated as withheld, allowing the page to measure what changes when each one is released.

2. Choose the material scope
  • Fabric only is the default. Component shortages do not prevent a job from being reported as unlocked.
  • Fabric and components requires every imported fabric and component requirement for the job to be covered.
  • Stock and PO supply are allocated to requirements in due-date order. A PO must arrive early enough for the configured material lead time.
3. Read the scenario sections
  • Supplier Release Impact recalculates the combined effect of releasing all remaining candidate POs for one supplier.
  • Single PO Release Impact tests one PO release at a time.
  • Bundled PO Release Impact shows combinations of two or three POs that unlock jobs which the individual POs cannot unlock alone.
  • Expand a row to inspect included POs, unlocked jobs, and remaining blockers.
4. Record decisions

Tick releases in the single-PO table and select Review staged POs to calculate their combined impact and save it as your staged decision. Review the staged cash and value summary, then select Commit staged POs when the release decision is made. Committed releases remain available in the baseline and disappear from future recommendations.

5. Persistence across sync

Staged and committed decisions are saved to the database, not the page URL, so they survive the daily Epicor sync. A committed release drops off automatically once it is fully received into stock. A staged decision is never auto-committed — if the daily sync changes its calculated impact before you commit it, a banner will flag what changed so you can re-review before deciding.

Blocked jobs reached
Jobs linked to the scenario that are short in the baseline. Jobs already covered by stock or committed supply are excluded.
Jobs / orders unlocked
A job is unlocked when all requirements in the selected scope are covered. An order is unlocked only when every linked job is unlocked.
Cash and value
Cash proxy is outstanding PO value, not the accounts-payable amount. Value less cash is unlocked sales value minus that proxy and is not profit or margin.
Value / cash
Unlocked sales-order value divided by cash proxy. For example, 5.0x means £5 of order value is unlocked for each £1 of outstanding PO value.
