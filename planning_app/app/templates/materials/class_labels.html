What does this do?

  • Class IDs come from Epicor's Part_ClassID and are otherwise opaque codes.
  • Labels are used on the Material and Component Shortage Reports — in the class filter dropdown, chart legends, and summary/detail tables.
  • Saving a label with the same class ID updates the existing entry.
  • Clearing a label's text (or deleting it) reverts that class back to showing its raw ID.
  • Labels persist across daily data imports — they are not affected by the CSV refresh.
